# Prototype review

Compare the same alpha plates under each recipe. Inspect actual exported SVGs, then open the `.blend` file and change the exposed controls. A useful option changes construction rules without rewriting the script.

Check ink order, physical SVG units, mark shape, spacing, rotation, and gaps. A plausible digital preview does not establish brush calibration. Compare RGB and Mixbox recompositions explicitly; applying Mixbox to RGB-solved plates is a diagnostic, not a Mixbox-optimized solve.

Keep the accepted reference and the rejected variants as evidence. The owner decides which options to develop after viewing the prototype.
