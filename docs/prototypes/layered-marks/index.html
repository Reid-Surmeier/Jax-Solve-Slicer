JAX layered marks: Close reference

JAX picks, for every grid cell and every ink, one tool mark (or none) and a dilution. Marks overlap and stack, so mixtures come from underlayers. Print order is fixed: yellow → orange → rose → red → sepia → burgundy → green → blue → purple → royal blue → blue black → black. Tools are placeholders.
