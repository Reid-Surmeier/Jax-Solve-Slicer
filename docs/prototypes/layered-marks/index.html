JAX layered marks: Close reference

Six square-based tools (wash, large, medium and small squares, slab, chip), fixed size, freely rotated. JAX picks, for every placement cell and every ink, one tool (or none), a dilution, an offset and a rotation. Marks overlap their neighbours; pale washes underneath shine through the darker marks printed later. Print order is fixed: yellow → orange → rose → red → sepia → burgundy → green → blue → purple → royal blue → blue black → black. Tools are placeholders.
